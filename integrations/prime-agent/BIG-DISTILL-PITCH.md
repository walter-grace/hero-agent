# Play #3: Big Distill → Prime Intellect environments (BD, not code)

A one-page pitch for a data/BD conversation with Prime Intellect. This is the deepest strategic fit
of the three plays and the natural bridge to a real endorsement. It is not an integration to build
yet; it is the case to make.

## The one-liner
Hero Run turns real agent work into training data you own; Prime Intellect turns training data into
open models. We are the same flywheel from two ends. Let's connect them: **Big Distill's curated
corpus becomes inputs to your Verifiers environments and the training runs $HERO exists to fund.**

## Why us, why now
- **Shared thesis.** Hero Run's entire reason to exist is to fund one frontier open-source training
  run with inference fees. Prime Intellect builds the decentralized training stack (INTELLECT models,
  prime-rl, Verifiers, the 2,500+ environment hub) that a fund like ours should point at.
- **We generate the raw material you want.** Prime Intellect's own site pitches "turn production
  traces into the next training run." That input is exactly what Hero Run produces: agent trajectories
  and distilled memory from hero-agent (and now from prime-agent running on the $HERO rail, see
  Play #1). Big Distill is the curation layer on top: agent-memory artifacts → a reviewed, licensed,
  public corpus.
- **Ownership + provenance are built in.** Every artifact is wallet-owned and, where public, hash-
  chain verifiable on Robinhood Chain. That is clean provenance for a training set, not scraped data
  of unknown origin.

## The concrete ask (pick the smallest first)
1. **Data → environments.** Take a slice of the public Big Distill corpus (opt-in, licensed, deduped)
   and shape it into one or more Verifiers-format RL environments or an eval set. Start with a single
   task family where our traces are dense.
2. **A funded run.** $HERO fees accrue to a treasury earmarked for a training run. The obvious joint
   move is co-funding or sponsoring a run on Prime Intellect infrastructure, with the resulting model
   open-sourced. Hero Run supplies the funding narrative + the data; Prime Intellect supplies the
   compute + training pipeline.
3. **Endorsement loop.** prime-agent running paid-in-$HERO (Play #1) is a live, demonstrable "Prime
   Intellect's own agent runs on the open-inference rail." That is a shippable proof point to anchor
   the conversation before any deeper commitment.

## What we bring / what they bring
| Hero Run | Prime Intellect |
| --- | --- |
| $HERO inference rail (500+ models, one flat price) | Decentralized training + RL stack |
| Wallet-owned, verifiable agent memory + trajectories | Verifiers environment format + 2,500-env hub |
| Big Distill: curated, licensed, public corpus | The open models the fund is meant to produce |
| A funding flywheel (inference fees → the run) | The compute + expertise to spend it well |

## Guardrails (so the pitch is credible)
- **Public + opt-in only.** Only the public, consented Big Distill corpus is ever offered. Private,
  encrypted agent memory never leaves the owner; that is the moat and it is non-negotiable.
- **Licensing up front.** The corpus ships with a clear training license so downstream use is clean.
- **Small first slice.** One environment or one eval set proves the pipeline before anyone commits to
  a co-funded run.

## The narrative in one breath
"Agents pay $HERO to think and to remember. That memory, curated and public, becomes training data.
That data trains an open model on Prime Intellect. That model makes inference cheaper, so agents pay
less to think. The loop funds itself, and both ends are open." That is the story to walk into the room
with.
